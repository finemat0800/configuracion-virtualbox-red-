# configuracion-virtualbox-red-
Justificacion 
Elegí modo de red interna ya que de esta manera estaría protegiendo mi internet de cualquier prueba que estaría haciendo desde el virtual box, en lo que se basa prácticamente en dejar sin conexión la computadora virtual y de esa manera cuando este probando algún malware entonces no llegue de ninguna forma a mi internet local, el caso de porque no elegi el modo adaptador puente o también llamado bridged es por el simple hecho que puede poner en peligro mi maquina ya que al elegir esta opción la computadora virtual estaría conectada al router de mi casa y de esta forma cuando este haciendo alguna prueba con algún virus el atacante podría dirigirse fácilmente a mi internet y de esta manera seria mejor utilizar otra opción ya que dejaría el entorno virtual aislado y controlado
